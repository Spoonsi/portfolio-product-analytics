# Оценка бонусной механики — конверсия в первую покупку

> Учебный проект. Копии исходных данных не публикуются по условиям проекта.

## Задача
Проверить, повышает ли бонус за первую покупку конверсию пользователей TikTok в маркетплейсе из регистрации в покупку.

## Данные и доступ
Ноутбук загружает данные по публичным ссылкам хранилища курса. Повторный запуск зависит от доступности и неизменности ссылок и файлов.

## Подход
Исследованы события и покупки, рассчитаны конверсии тестовой и контрольной групп, проверена статистическая значимость различий и рассмотрена динамика выручки на пользователя.

## Результат
Конверсия в первую покупку выросла с 1,06% до 7,51% (p < 0,001). ROI Affiliate и SEO превышает 900%, ROI TikTok составляет −67%; удержание снижается до 3% к третьему месяцу.
