# Поиск точек роста сервиса доставки

> Учебный проект. Копия исходных данных не публикуется по условиям проекта.

## Задача
Найти потери в пути пользователя сервиса «Всё.из.кафе» и определить сегменты клиентов для продуктовых рекомендаций.

## Данные и доступ
Ноутбук загружает данные по публичной ссылке хранилища курса. Повторный запуск зависит от доступности и неизменности ссылки и файла.

## Подход
Исследованы воронка до заказа и мобильные этапы, повторные покупки и число заказов; выполнена RFM-сегментация клиентов и кластеризация ресторанов методом K-Means по заказам, среднему чеку и ассортименту.

## Результат
Общая конверсия в заказ — 33%; на подтверждении телефона мобильная конверсия составляет 55% против 91% на десктопе. 60% покупателей сделали один заказ; выделен VIP-сегмент из 68 клиентов, рестораны разделены на четыре кластера.
