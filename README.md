# Портфолио продуктового аналитика

Учебные и курсовые проекты по продуктовой аналитике, SQL, BI и обработке данных. В подборке сначала — проекты, в которых задача и результат связаны с продуктовыми решениями; затем — SQL-кейсы, дашборды и дополнительные исследования.

> **Данные и воспроизводимость.** В проектах используются учебные наборы данных из хранилищ курса, учебной среды и баз данных. Источники и необходимые для работы файлы описаны в README соответствующих проектов. Дашборды опубликованы в Yandex DataLens.

**Стек:** Python (pandas, NumPy, SciPy, statsmodels, scikit-learn, Matplotlib, Seaborn), SQL (PostgreSQL, ClickHouse), Yandex DataLens, PySpark, Apache Airflow, Yandex Cloud Dataproc, Amazon S3.
