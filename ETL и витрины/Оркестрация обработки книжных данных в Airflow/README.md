# Оркестрация обработки книжных данных в Airflow

> Учебный проект. Данные и реальные параметры подключения не публикуются по NDA.

## Задача
Описать пакетную обработку данных книжного сервиса и подготовку аналитических витрин с помощью Spark и оркестратора.

## Данные и доступ
Исходные данные не включены в репозиторий. Параметры подключения в ноутбуке заменены заглушками `hostname_was_here`, `database_was_here`, `username_was_here` и `password_was_here`.

## Подход
Подготовлен PySpark-код и DAG с зависимостями, запуском Spark-job через Airflow и Dataproc, проверкой файлов в Amazon S3 и описанием обновления витрин.

## Результат
Собран процесс пакетной обработки, связывающий проверку входных файлов, запуск Spark-job и обновление аналитических витрин через Airflow.
