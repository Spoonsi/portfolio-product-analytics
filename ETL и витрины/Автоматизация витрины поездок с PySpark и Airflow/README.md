# Автоматизация витрины поездок с PySpark и Airflow

> Учебный проект по построению и оркестрации аналитического пайплайна.

## Задача
Подготовить агрегированную витрину поездок и описать автоматизацию пакетного процесса.

## Данные и доступ
Данные читаются из учебного S3-хранилища. Параметры подключения к ClickHouse представлены в ноутбуке заглушками `hostname_was_here`, `database_was_here`, `username_was_here` и `password_was_here`.

## Подход
Подготовлены PySpark-агрегация, схема итоговой таблицы и DAG Airflow для запуска Spark-job через Dataproc с проверкой появления входных файлов в Amazon S3.

## Результат
Пакетный процесс включает проверку поступления файлов в Amazon S3, обработку поездок в Spark и создание агрегированной таблицы в ClickHouse. Airflow связывает этапы пайплайна и управляет их последовательностью.
