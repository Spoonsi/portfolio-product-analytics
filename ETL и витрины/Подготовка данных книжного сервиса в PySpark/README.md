# Подготовка данных книжного сервиса в PySpark

> Учебный проект. Исходные данные не включены в репозиторий.

## Задача
Подготовить связанные данные об активности пользователей и контенте книжного сервиса для последующего анализа.

## Данные и доступ
Ноутбук ожидает `audition.csv` и `content.csv` в рабочей директории. Файлы не загружаются автоматически; повторный запуск требует разрешённого доступа к учебным данным.

## Подход
В PySpark созданы сессия и аналитические выборки; проверены типы и структура, выполнены фильтрация, типизация, обработка дат, объединение и агрегирование данных.

## Результат
Сформированы аналитические выборки, объединяющие активность пользователей и информацию о контенте книжного сервиса.
