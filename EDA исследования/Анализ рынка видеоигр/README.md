# Анализ рынка видеоигр — платформы и оценки

> Учебный проект. Исходный файл не включён в репозиторий.

## Задача
Оценить структуру рынка видеоигр в 2000–2013 годах и сравнить платформы и характеристики игр, важные для планирования продаж.

## Данные и доступ
Ноутбук читает `/datasets/new_games.csv` из учебной среды; публичной ссылки нет. Запуск из GitHub требует разрешённого доступа к файлу.

## Подход
Проверены структура, типы и пропуски; выполнена предобработка, сопоставлена динамика выпуска по годам и платформам, изучены пользовательские и критические оценки.

## Результат
В наборе 16 956 игр за 2000–2013 годы; по числу игр выделяются Nintendo DS и PlayStation 2. При интерпретации оценок учитывается высокая доля игр без пользовательских и критических оценок.
