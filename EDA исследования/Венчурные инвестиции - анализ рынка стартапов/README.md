# Венчурные инвестиции — анализ рынка стартапов

> Учебный проект. Исходные данные не включены в репозиторий.

## Задача
Исследовать динамику венчурных инвестиций и возврат средств, чтобы сравнить отраслевые направления и типы финансирования.

## Данные и доступ
Архив инвестиций загружается по публичной ссылке хранилища курса; таблица возвратов читается из `/datasets/cb_returns.csv`. Полный повторный запуск вне учебной среды требует разрешённого доступа к файлу.

## Подход
Проверены структура, пропуски, дубликаты и типы данных; сравнивались объёмы и динамика финансирования по годам, отраслям и типам, а также показатели возврата.

## Результат
В 2014 году финансирование выросло в 12 массовых сегментах; устойчивый рост в 2011–2014 годах отмечен для шести, включая E-commerce и Real Estate. Debt financing показал наиболее устойчивую динамику возврата среди рассмотренных типов.

## Ограничения
Рекомендации основаны только на показателях исследованного набора; повторный запуск зависит от доступа к файлу возвратов.
