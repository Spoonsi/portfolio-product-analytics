# Рынок заведений общественного питания Москвы

> Учебный проект. Исходные данные не включены в репозиторий.

## Задача
Изучить распределение заведений Москвы по категориям и районам и исследовать, какие характеристики связаны с рейтингами.

## Данные и доступ
Ноутбук читает `rest_info.csv` и `rest_price.csv` из `/datasets` учебной среды; публичных ссылок нет. Для корреляционного анализа требуется `phik`.

## Подход
Проверены структура и полнота данных, выполнены предобработка и объединение; сравнивались категории, округа, сетевой формат, посадочные места, рейтинги и цены.

## Результат
В выборке 2 376 кафе и 2 042 ресторана; в Центральном административном округе — 2 242 заведения. Несетевые заведения составляют около 61,9%; сильной связи рейтинга с рассмотренными числовыми признаками не выявлено.

## Ограничения
Повторный запуск из GitHub требует разрешённого доступа к файлам учебной среды. Выводы описывают исследованную выборку.
